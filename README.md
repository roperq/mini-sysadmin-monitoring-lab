			MINI SYSADMIN MONITORING LAB

OVERVIEW:
	A beginner system administration project built to practice system health monitoring, troubleshooting, and automation using Python and macOS>

GOALS:
	Monitoring system resource usage.
	Identify potential system health issues.
	Practice results and document troubleshooting.
	Build practical skills for an IT Support and System Administraton career.

TECHNOLOGIES:
	Python
	macOS Terminal
	Git and GitHub
	Networking utilites

PROJECT STRUCTURE:
	scripts/- Monitoring and automation scripts.
	logs/- Location for generated monitoring logs.
	documentation/- Lab notes and troubleshooting records.
	docs/- Additional project documentation.

CURRENT FEATURES:
	Features are being developed and tested as the progresses. See the scripts and documentation for the current implementation.

LEARNING OUTCOMES:
	This project provides hands-on practice with command-line navigation, scripting, system monitoring, troubleshooting, and version control.

FUTURE IMPROVEMENTS:
	Improve persistent logging.
	Expand network connectivity monitoring.
	Refine warning thresholds.
	Add Arduino-based status indicators.
	Improve testing and usage documentation.

AUTHOR:
	An independent beginner system administration lab project created for learing and portfolio development.
